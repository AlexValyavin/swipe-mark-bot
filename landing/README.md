# Landing (GitHub Pages)

Статический лэндинг «SwipeMark — разгреби свои сохранёнки». Двуязычный (РУ/EN): переключатель в правом верхнем углу, выбор сохраняется в `localStorage`.

## Как задеплоить

Push в ветку `main` по пути `landing/**` автоматически публикует сайт на GitHub Pages (см. `.github/workflows/deploy-landing.yml`).

URL: `https://<user>.github.io/<repo>/`

## Скриншоты

Положи скриншоты приложения в `landing/screenshots/` с этими именами (PNG, 9:16, желательно ~828×1472):

| Файл | Что показывает |
|---|---|
| `deck.png` | Колода карточек с прогрессом разбора |
| `card.png` | Карточка: заголовок, «Кратко», теги |
| `completion.png` | Экран завершения с итогами сессии |
| `library.png` | Мои сохранёнки: папки, теги, поиск |
| `onboarding.png` | Онбординг при первом входе |
| `empty.png` | Пустая колода с кнопкой «Открыть бота» |

Пока файла нет, картинка не загрузится (серый placeholder). После push лэндинг обновится сам.
